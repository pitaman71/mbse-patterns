# Test plan

One suite per notebook, with the same case IDs, in the same order, in both implementations; each case is a markdown
cell `## ID · title` followed by one code cell. `support.py` holds the shared helpers and the address book the suites
use: a singleton directory lists contacts, and contacts own phones, each phone with one entry. TypeScript's plan lists
only its differences.

| Notebook | Suite | Cases | Covers |
|---|---|---|---|
| `01_Predicates.ipynb` | CON | 7 | A predicate built fluently (name, description, symbols and parameters added in order, conditions from a lambda or a writer, which `requires` and `forbids` add up, the builder's declared variables; clone, update, resolve, and the builder's refusals); static problems (no constraint, a symbol's schema not a named object schema, non-core operations, unbound names) and `check` (labelled by name, a predicate of a set without a name, a name defined twice, a set of non-predicates); a set's order and builder; predicates as data (symbols written by schema name with any store, a shared constraint written once, read back through `OfStore(store)` to the store's schemas, refused through `Builders` for named schemas, an inline schema, an untyped parameter and a typed, described one round trip, parameters as `OfParameter`s from data or specs, mbse-schemas' validation, `update` through the store); decoding refused (a constraint at another index, an unset link) and a set of non-predicates read then refused, a blank predicate; `register` in a proxy store; a predicate applied by reference (its arguments bound to its symbols in order and its parameters in order or by name, the same term either way, partial application, an unbound parameter unknown, `call`, refusals of too many arguments, unknown names and a parameter given twice, problems of a wrong number of symbols, unknown names and a repeated name, a non-predicate, evaluation, the names of the parameters given written with each application and none for none, written once and read back as one object, recursion: valid, a recursion nothing decides unknown, one a condition decides evaluated, written once and read back recursive) |
